Practical review checklist

1. Missing alt: Decide whether the image conveys information. Add concise meaning for informative images, or use alt="" where appropriate for decorative images.

2. Empty alt: Do not automatically treat it as a defect. Confirm that surrounding links and controls still have clear accessible names.

3. Vague alt: Filenames and labels such as “image” do not explain purpose. Add a meaningful description when content is informative.

4. Full review: This tool does not analyze CSS background images, SVG semantics, accessibility trees, images generated by JavaScript, or alt quality in context. A manual WCAG review is still necessary.
