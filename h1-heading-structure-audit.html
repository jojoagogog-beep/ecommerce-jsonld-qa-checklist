      What this local checker covers

      It recognizes <h1> tags in pasted static HTML and ignores HTML comments and the contents of script, style and textarea blocks. It reports unmatched H1 start tags, empty headings, and multiple headings for manual review.

      It does not inspect heading order across H2–H6, visually hidden content, browser accessibility trees, DOM changes from JavaScript, or assistive-technology behavior. Consider the page context before changing its headings.
