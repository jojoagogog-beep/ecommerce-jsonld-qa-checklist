What this quick checker can and cannot verify

This free local tool reads <link rel="alternate" hreflang="…" href="…"> tags from pasted HTML. It performs basic syntactic checks only. It does not fetch your website, test HTTP status, verify actual country/language content, assess canonicals, crawl sitemaps, or confirm reciprocal hreflang links across pages. It does not guarantee search-engine behavior.

For a repeatable audit of up to 18 public HTTPS URLs, use the hosted PAL Hreflang Tag Checker on Apify. It inspects static HTML pages and exports findings in CSV/JSON. Review the current Pricing tab before running; successful page checks may be billable.
